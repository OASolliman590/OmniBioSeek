# Contributing

1. Create a focused `codex/<milestone>` or `feature/<topic>` branch.
2. Never add real omics datasets, credentials, or generated matrices.
3. Add mocked or synthetic tests for every adapter/parser change.
4. Run `pytest`, `ruff`, and `mypy` before opening a draft pull request.
5. Describe query-semantic changes explicitly; they can change scientific recall.

Pull requests are squash-merged after required checks pass.
